# KTO 阅读笔记

**公开来源:** [KTO: Model Alignment as Prospect Theoretic Optimization](https://arxiv.org/abs/2302.01318)(Ethayarajh et al., 2023)。

## 核心观点

DPO 需要**成对比较**（A 比 B 好），但现实里这种标注很难拿。KTO 只需要**单个样本的好坏判断**——"这条回答是好的还是坏的"——用前景理论（prospect theory）的得失不对称性做优化。**更省数据的对齐方法。**

## 重要创新

- **单样本偏好**:不需要配对，只需要"好/坏"标签，数据获取门槛大降。
- **前景理论启发**:人对"得到"和"失去"的敏感度不对称——KTO 把"好样本该涨多少、坏样本该降多少"做成不对称的损失。
- **参考点**:以"模型对样本的平均满意程度"为参考，决定得失。

## 适用场景

- 数据只有好坏标签、没有配对比较时（如用户点赞/点踩）。
- 想要比 DPO 更少标注成本的对齐。

## 读什么

- KTO 和 DPO 的数据需求差异（单样本 vs 成对）。
- 前景理论的"损失厌恶"如何体现在损失函数里。
