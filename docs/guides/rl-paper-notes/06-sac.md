# SAC 阅读笔记

**公开来源:** [Soft Actor-Critic: Off-Policy Maximum Entropy Deep Reinforcement Learning with a Stochastic Actor](https://arxiv.org/abs/1801.01290)(Haarnoja et al., 2018)。

## 核心观点

**最大熵强化学习**：在"拿高分"和"保持随机探索"之间显式平衡。目标函数除了最大化回报，还加一项**熵奖励**（鼓励策略保持随机），让智能体既会拿高分、又不至于过早收敛到单一行为。

## 重要创新

- **熵正则化**:`回报 + α × 熵`，α 是温度系数（自动调节）。熵高 = 动作分布更随机 = 探索更多。
- **随机 actor**:策略输出概率分布，天然带探索，不像 DDPG 要靠加噪声。
- **软更新 + 双 Q 网络**:两个 critic 取最小值防高估，目标网络软更新，训练稳定。

## 为什么重要

- 连续控制任务的 SOTA 之一，机器人/自动驾驶常用。
- "探索 vs 利用"的平衡被它做成可调、可学的目标，而非启发式。

## 读什么

- 熵奖励为什么能带来更好的探索（避免过早收敛到局部最优）。
- 与 DDPG 的对比：随机策略 vs 确定性策略 + 噪声。
