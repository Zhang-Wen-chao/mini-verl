> 来源：B 站「耿直哥」——《【PPO算法】强化学习头牌，学大模型必懂》
> 本文是根据视频中文字幕整理的学习笔记，保留动画讲解的叙事顺序，修正了语音识别的错别字。

## 1. 开场：PPO 为什么是"头牌"

- 强化学习入门第一算法，徒子徒孙开枝散叶，在大模型推理界发扬光大。
- 核心印象：**一个 clip 函数，暴力直接，效果奇好**。
- PPO 就是 TRPO 的**牛逼简化版**（Schulman 在 OpenAI 时期设计）。

## 2. 问题设定（承接 TRPO）

- 神经网络输入状态 `s_t` 输出动作 `a_t`；权重可排成高维向量 θ，投影到数轴是一个点。
- 该点对应性能分数 `η(θ)`，动起来就是目标函数曲线，训练目标是找顶点 `θ*`。
- **强化学习的特殊性**：没有 η 的解析式，不能直接梯度上升，只能写成迭代形式。
- 公式看不懂没关系，用动画理解：
  - 像站在山上，看不见前后山形，只知道当下海拔高度；
  - 此时已知：旧策略 `π_θ_old`、邻域内上下抖度 A（优势函数）；
  - 未知：新策略 `π'`、状态转移 `ρ`。目标 = 安全搜索，尽快找到山顶。

## 3. TRPO 的解法 vs 其缺点

- TRPO 简化目标函数，创造性地设计**信赖域**：每步行走时下方设置一个踏实的安全区（KL 散度约束）。
- **很有效，但计算又慢又笨、很复杂。**

## 4. PPO 的灵感：概率比值 + clip

- 天才的 Schulman（当时是 OpenAI 联创）灵感爆发：
  - 把**概率比值**定义为 `r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)`；
  - 干脆给它限定一个动态范围：`[1−ε, 1+ε]`（批龙 = epsilon）。
  - **这就是 clip 函数的来源。**

### 4.1 clip 曲线为什么长这样（动画拆解）

- 网上资料大多直接给这张图，但很难明白怎么运作；叠加到一起看就好懂了。
- **真实回报曲线不光滑**，有起起伏伏的波动；红线是平滑后的均值，我们希望沿它上升且不受噪声影响。
- 局部放大后 = 找邻域内峰值。

**A > 0（站在红线左侧，朝向局部山峰）**
- 打算沿切线 L 往上走；但**步子太大会错过真正峰值**。
- clip 函数指定一个水平区域限制行动范围，避免冲太快或误入歧途。

**A < 0（站在红线右侧，背离局部山峰）**
- 必须回撤才能找到峰值；沿切线 L 走同样太猛会错过。
- clip 函数增加限定区域限制回撤幅度，避免步子过大。

**两种情况统一读法**
- A>0 时斜率为正：先沿 L，到 `1+ε` 处弯折限幅；
- A<0 时斜率为负：先沿 L，到 `1−ε` 处弯折限幅；
- 不管哪种，都是为了保证**搜索步长别太大**。

## 5. PPO 的本质

- PPO 用严谨的数学语言定义 clip 函数，本质上是一种**新的动态信赖域**（对邻域进行约束）。
- 名字：**Proximal（近端）Policy Optimization**——因为是对邻域进行约束。
- 优点：**计算量小、更稳定、少量代码即可实现**，一度成为 OpenAI 核心算法，推广到 Gym 等框架，成为新人入门首选。

## 6. 思想谱系：从 PPO 到大模型对齐

PPO 的"工程化约束思想"启发了大量研究者，沿着"稳定更新 + 可控偏移"的思路提出改进：

- DeepSeek 的 **GRPO / DAPO**
- Anthropic 的 **RLHF / Constitutional AI**
- **DPO / ORPO / KTO** 等

它们把强化学习的最优解思想，转化为大模型与人类对齐的优化框架，开创了整个 LLM 对齐家族的演化历程。
