# DAPO 算法动画拆解（视频笔记）

> 来源：B 站「耿直哥」——《【DAPO算法】动画拆解：DeepSeek、豆包背后的"稳重"进化，8分钟看懂！》
> 本文是根据视频中文字幕整理的学习笔记，保留动画讲解的叙事顺序，修正了语音识别的错别字。

## 1. 开场：主流大模型 RL 算法谱系

- 主流大模型（GPT / Claude / DeepSeek）背后，深度强化学习越来越重要。
- 进化旅程：**TRPO → PPO → GRPO → DAPO**，逐步解决训练效率与稳定性问题。
- 动画人格化比喻：

| 算法 | 比喻 | 特点 |
|---|---|---|
| TRPO | 谨慎的老太太 | 每步小心确认，脚下踏实信赖域；理论严谨但计算复杂、效率低 |
| PPO | 精明的小脚女人 | 用 clip 函数限定在一定范围内前进；简化计算、通用性强，但细腻有余、过于谨慎 |
| GRPO | 勇敢的野小子 | 面对光秃秃的石头山，眼观六路迈开大步，用组内奖励替代价值网络；但可能有些冒进 |
| DAPO | 成熟青年 | 在 GRPO 基础上增加稳定机制、优化训练技巧，解决实战痛点——**既有速度也有稳定性** |

## 2. DAPO 的四项改进（先上目标函数）

1. 引入 clip 函数，并**微调 epsilon 参数**；
2. 增加对**输出 O 的限制条件**（与目标答案的相似度）；
3. 引入 **token 级别的归一化方法**；
4. 修改**奖励打分模型 R 公式**（长度感知的精细化惩罚）。

## 3. 改进一：优化 clip 函数（上界宽、下界窄）

- 重新引入 clip 函数 = 增加每步移动的限定范围。
- 与 PPO 相比**放宽上下区域**：用两个不同边界控制——
  - `ε_high` 更大（上界宽）
  - `ε_low` 相对较小（下界窄）
- 针对 NLP 任务特点（爬光秃秃石头山）：对比 GRPO，通过设置边界**减少了冒进**——大胆探索的同时增加边界感，又快又稳。

## 4. 改进二：限制输出 O 与目标答案的相似度

- 约束：每个输出 `O_i` 与目标答案 A 足够相似，且在区间 [0, G] 之间。
- 动机：GRPO 每个时间步生成多个探索输出，`O_i` 彼此**没有权重差异**，显然不合理：
  - 万一某个 O 很"变态"（偏离目标太远），会把算法带到沟里；
  - 如果所有 O 过于相似甚至重复，就**失去了探索的意义**。
- DAPO 增加约束 = 探索不能偏离目标太远：避免危险尝试，也**减少集体作弊**，提升稳定性。

## 5. 改进三：token 级别的归一化（保护长序列）

- 对比 GRPO 与 DAPO 目标函数中**归一化的顺序**发生了微妙变化：

| | 归一化顺序 | 问题 |
|---|---|---|
| GRPO | 最内层 Σ 角标是 T → **先在序列 O_i 内平均**，再对样本序列求平均 | 长序列内部平均后只是一个数，在全体样本中的**重要性被稀释** |
| DAPO | 归一化放到**最外层** → 不是序列内先平均再对比，而是**所有 token 一起对比、一起平均** | 长序列的重要性得以保留，兼顾序列与每个 token 的作用 |

- 动画直观解释：长预测序列本来挺好，但先被自己归一化成一个数值再与别的序列对比，重要性就稀释了；DAPO 让全体 token（所有原点）一起考虑，实现**粗细两种尺度的综合考量**。

## 6. 改进四：长度感知的奖励惩罚（渐进式奖惩）

- 旧 GRPO 奖励非常粗糙：正确 +1、错误 −1；输出太长被截断也直接判错——显然不合理。
- DAPO 根据序列长度**分段调整**：
  - 在安全范围内：**不惩罚（等于 0）**；
  - 在一定缓冲区内：从 0 到 −1 **线性增加**；
  - 超过最大长度：**固定惩罚 1**。
- 效果 = 鼓励深度探索：
  - 原来长路线很容易被判错、被扼杀；
  - 现在只要路线有价值，即使长一点也能获得奖励。
- 对**数学推理、逻辑证明**等任务至关重要。

## 7. 小结：DAPO 四方面改进

1. **优化 clip 函数**（上宽下窄的 epsilon）→ 提升稳定性；
2. **限定输出相似度** → 减少危险尝试和同质化；
3. **token 级别归一化** → 保护长序列的话语权；
4. **渐进式奖惩** → 鼓励深度探索。

> DAPO 站在 PPO 和 GRPO 的肩膀上更上一层楼，在大模型强化学习训练领域达到新高度。
