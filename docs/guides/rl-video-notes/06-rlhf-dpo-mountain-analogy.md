## 1. 开场：面试必考题

- 很多面试都考 **RLHF 和 DPO 的区别**，搞大模型必知必会。
- 本文用一个"男女朋友爬山"的例子深入浅出讲清楚。

## 2. RLHF 三步走（网络盘点）

RLHF（ChatGPT 出圈的头号功臣）最常见流程图有三步：

1. **预训练 + SFT 微调**；
2. **奖励模型（RM）训练**；
3. **PPO 强化学习**。

### 2.1 每个网络是什么

| 网络 | 爬山比喻 | 角色 |
|---|---|---|
| 参考模型（`π_ref`） | 先爬到**中天门**的你 | 初始阶段内的 best，但还不是全局最优；是继续优化的起点 |
| 奖励模型 RM | 一起爬山的**女朋友** | 专司奖励计算：输入状态输出打分，每步对你指指点点 |
| Actor（`π_θ`） | 当前的你 | PPO 中要继续迭代的策略网络 |
| Critic | 女朋友的**经验预测** | 输入当前状态 `s_t` 输出 `V_t` = 未来很多步奖励 R 的折扣期望（预测你最终能爬多高） |

**为什么有人说三个网络、有人说四个？**
- **结构上**只有三个：Actor + RM + Critic（你自己、女朋友、她的经验预测）；
- **实际执行上**因为增加了参考模型 `π_ref`（"曾经的你"）→ **四个**。
- 面试官爱问这个，因为它能看出你的理解深度。

### 2.2 优势 A 的推导（爬山版）

- `r_t` = 当前动作的即时打分（女朋友当场给了即时正反馈，如 +5 米）；
- `γ · V(s_{t+1})` = 未来预测打折扣（如 0.9 × 85 = 76.5 米，未来有不确定性要打折）；
- `V(s_t)` = t 时刻 Critic 的输出（原来觉得你能爬 80 米）；
- **总价值** = `r_t + γ·V(s_{t+1})` = 5 + 76.5 = 81.5 米；
- **优势** `A_t` = 81.5 − 80 = **+1.5 米** → 讲笑话是惊喜，以后要多干；
- 反之 A_t 为负 → 以后少干这种事。

### 2.3 PPO 目标函数（RLHF 版）

- `ratio` = 当前策略/参考策略的比值 `π_θ / π_ref`；
- 借助外部优势 `A_t` 先调整比值 ratio，进而调整行动策略 π——好比在女朋友陪伴下不断寻找更优路线、爬上更高山峰。
- **Actor 与参考模型结构完全相同，只是权重不同**（就像你还是你，只是山上位置不同：参考位置在中天门，你要努力爬到南天门/玉皇顶）。
- 实际执行时为方便计算，RLHF 会一口气 load 两个模型，并在目标函数里加一个 **KL 散度**，保证当前策略别偏离参考策略太远（爬山时不断回头瞄参考位置，防止迷失方向）。

## 3. DPO：直接偏好优化

### 3.1 核心发现

- 全称 **Direct Preference Optimization**（直接偏好优化），RLHF 的进化版，已成为国内外大模型主流训练算法。
- 牛掰之处：发现了一个秘密——**RLHF 中的当前策略 π 正比于 参考策略 × 奖励 R 的指数函数**：
  ```
  π ∝ π_ref · exp(R / β)
  ```
- 因此 R 可以表达为**两个策略的 log 差乘以系数 β**：
  ```
  R = β · log(π/π_ref)
  ```
- **人话**：RM 模型费劲巴拉训练半天，合着用策略本身就能表示！
- 于是：RM 模型其实**有没有就无所谓了**，也不需要"老实的" PPO——把人类偏好的对齐数据**直接喂给 Actor** 即可。

### 3.2 目标函数（y⁺ / y⁻）

- 目标函数乍一看 `y⁺`（chosen）和 `y⁻`（rejected）容易让小白迷糊，它来自**二元偏好学习（pairwise ranking）**——推荐系统排序学习的成熟范式。
- 一句话对比：
  - **PPO / RLHF**：走**绝对奖励分数**路线；
  - **DPO**：采用**相对分数**（正负奖励差），Sigmoid 函数可进一步表示为策略 π 的 log 差。

### 3.3 DPO 需要的网络

- DPO 只需要**两个网络**：参考模型 `π_ref` + Actor `π_θ`（结构一致，一静一动）。
- 仍以参考模型为基准点不断优化：相当于女朋友爬到中天门不走了，尽管没有她陪伴，但只要你牢记她的嘱托、一步一步往高处走、每步回头瞄一瞄别偏离方向，一样能快速抵达山顶。

## 4. 主线 vs 支线：两类算法定位

- 深度强化学习旅程中讲过的 **TRPO / PPO / GRPO / DAPO** 是**通用的优化框架**（主线任务）：主要解决**大模型"会不会"**的问题（能力）。
- **RLHF / DPO** 算是**支线任务**：强调与**人类价值观的对齐**（三观）。
- 毕竟模型能力再强，三观不一致也有害无益。
