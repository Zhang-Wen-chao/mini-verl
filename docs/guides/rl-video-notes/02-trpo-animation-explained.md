# TRPO 算法动画拆解（视频笔记）

> 本文是根据视频中文字幕整理的学习笔记，保留动画讲解的叙事顺序，修正了语音识别的错别字。

## 1. 开场：爬山比喻

- **闭眼爬山**：每次只能往前一步；迈太大一脚踩空，迈太小半天走不到终点。
- 模型更新策略面临同样难题：**步子太大容易崩，太小收敛太慢**。
- TRPO 的回答：**给你画一条安全线**（trust region）。
- 地位：强化学习论文高引榜前十，曾是 OpenAI 的核心算法，让策略训练告别"一更新就崩盘"的玄学时代，开启稳定性革命。

## 2. 问题设定

- 神经网络：输入状态 `s_t`，输出动作 `a_t`。
- 网络权重成千上万，可排成高维向量 `θ`；投影到数轴上就是一个点。
- 对该点的性能打分记为 `η(θ)`，动起来就形成**目标函数曲线**，训练目的 = 找到顶点（最优参数 `θ*`）。
- **难点**：与深度学习不同，我们并不知道 `η` 函数的具体长相（没有解析式），只知道它能写成迭代形式。

### 迭代式里的符号

| 符号 | 含义 |
|---|---|
| `η(π)` | 当前策略的性能值（当前曲线值） |
| `θ_old` | 当前参数 |
| `π_old` | 旧策略（当前动作分布） |
| `A` | 当前动作的优势函数（上下抖度） |
| `π'` | 下一时刻的新策略 |
| `ρ` | 两个时刻间的状态转移 |

- 核心难点：**`π'` 和 `ρ` 都是未知的**。像站在山上但山形突然消失，只知道此刻海拔、当前动作分布和局部斜率 A，却不知道下一步该往哪走。

## 3. 朴素思路：梯度上升

- 沿切线方向走 = 在脚下铺一块木板。
- 问题：**该走多远？** 走太远会掉沟里，走太小又慢。
- 需要一种"既能大步走、又不会掉沟"的机制。

## 4. TRPO 的创造：信赖域（Trust Region）

### 4.1 安全线（KL 惩罚项）

- TRPO 构造新函数：在切线 L 下方画一条**安全线**（绿线）。
  ```
  新函数 = L − C × D_KL(π_old ‖ π')
  ```
- `D` = 新旧策略的 KL 散度，`C` 为常数。
- 直觉：站在当前点用脚试探一圈记下动作分布 `π_old(s_t)`，下一时刻再做一次得到 `π'(s_t)`；两者分布形状差异越大，说明地形变化越剧烈。把 KL 散度作为惩罚项从 L 中减去，得到更保守的绿线。
- 动画比喻：像一个人双手悬挂在木板 L 上向前滑动，同时用脚生生试探出一条可能的路。
- 找**绿线的顶点** = 更快、更安全地更新策略。

### 4.2 信赖域（KL 约束）

- 更进一步：直接在动作空间限定 KL 散度范围 `D_KL ≤ δ`（δ 映射到参数空间）。
- 效果：从当前点出发划定一个**灰色锅盖区域**，学名 **trust region（信赖域）**——这就是 TRPO 名字的来源。
- 比喻：地表下的岩层，够稳够硬，在这个区域里大胆移动不会掉沟里。
- 相比绿线：形状更平缓，**最大值离当前点更远 → 每步更新更大、收敛更快**。

## 5. L 的高效求法：重要性采样

- L 的真实公式包含未知的新策略 `π'`，TRPO 用**重要性采样**近似：
  1. 在旧策略 `π_old` 上采样；
  2. 假设一个新参数 θ 代入策略函数 `π'`，计算**比值** `π'(a|s) / π_old(a|s)`；
  3. 两个求和符号写成期望形式。
- 动画比喻：站在当前点，用策略 π 往前瞄准某个新策略 π' 扔钩子锚定，在当前点和锚点之间拉一条**悬索**——此时 L 不再是切线，而是微弯的曲线，作用相同：为安全探索构建临时保护。

## 6. 完整流程小结

1. 当前点对应参数 `θ_i` 和旧策略 `π_θ_i`；
2. 假定一个新参数 θ，找到临时策略 `π'`（锚点）；
3. 借助锚点搭建**悬索函数 L**；
4. 根据新旧策略分布的 KL 散度计算**信赖域**（像探地雷达照出的穹顶锅盖）；
5. 在灰色锅盖中找最高点，横坐标即新参数 `θ_{i+1}`；
6. 执行新策略 `π_{θ_{i+1}}`，得到真实 `η(θ_{i+1})`，作为下一轮探索起点；
7. 循环，即可在不知道真实 η 曲线的情况下，又快又稳地搜到顶点。

## 7. 一句话总结

> 即便缺乏清晰的目标函数地形图，TRPO 凭借"信赖域 = 安全探索区"的敏锐设计，走出了独特的最优化道路。
